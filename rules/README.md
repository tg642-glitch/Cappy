# Rules source

CAPPY uses the **FIA 2026 F1 Regulations, Section D (Financial, F1 Teams),
Iss 08, 1 October 2026**.

The PDF is **not included** in this repository. Download it yourself from
[fia.com](https://www.fia.com):

- [Section D, Iss 08 (PDF on fia.com)](https://www.fia.com/system/files/documents/fia_2026_f1_regulations_-_section_d_financial_-_f1_teams_-_iss_08_-_2026-10-01.pdf)

To use it, open CAPPY in live mode and load your downloaded copy. The page
reads the PDF in the browser.
